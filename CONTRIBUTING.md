# Contributing

Thank you for testing or improving Keylight Commander Linux. Reports in English or German are welcome.

## Report a bug or compatibility result

Search the [existing issues](https://github.com/Avacon00/elgatokeylight-commander-linux/issues) first, then use the [bug report form](https://github.com/Avacon00/elgatokeylight-commander-linux/issues/new/choose).

Please include:

- App version and installation method.
- Linux distribution and version.
- Desktop environment and display session (Wayland or X11).
- Key Light model and firmware when known.
- Clear steps to reproduce the problem, expected behavior and actual behavior.
- Relevant logs with passwords, tokens, serial numbers, MAC addresses and private network addresses removed.

Reports from distributions and desktops beyond Ubuntu 24.04 and Pop!_OS 24.04/COSMIC are especially useful because those environments have not yet been verified by the maintainer.

## Propose a change

For a substantial behavior change, open an issue before starting so the approach can be discussed. Keep pull requests focused and explain the trigger, resulting behavior and verification.

Before submitting code, run the checks documented in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Linux tray changes should also run the isolated native menu test on a desktop session when possible.

## Deutsch

Fehlerberichte und Testergebnisse auf Deutsch sind willkommen. Bitte App-Version, Distribution, Desktopumgebung, Wayland/X11, Lampenmodell, nachvollziehbare Schritte sowie erwartetes und tatsächliches Verhalten angeben. Persönliche Gerätekennungen und private Netzwerkdaten vor dem Hochladen aus Logs entfernen.
